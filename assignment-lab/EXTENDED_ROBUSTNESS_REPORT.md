# 2차 확장 강건성 시험

## 시험 규모

기존 2차 Monte Carlo는 난수 시드 하나에서 60개 충돌 사례와 60개 대응
무충돌 기준 실행을 사용했다. 확장 시험은 서로 독립적인 시드 5개에서 각각
100개씩 생성했다.

- 충돌 사례: 500개
- 같은 물체·환경의 무충돌 기준 실행: 500개
- 총 MuJoCo 에피소드: 1,000회
- 시드: `20261103`–`20261107`
- 충돌력: 임의 3D 방향, 15–60 N
- 물체·환경 범위: `PHASE2_REPORT.md`와 동일

충돌 후 경보가 있어도 같은 조건의 무충돌 실행에서 경보가 겹치거나 충돌 전에
이미 경보가 발생한 경우에는 성공으로 세지 않았다.

## 결과

| 지표 | 결과 |
|---|---:|
| 충돌 구분 | **475/500 (95.0%)** |
| 구분률 Wilson 95% 구간 | **92.7–96.6%** |
| 실패 | 25/500 |
| 무충돌 기준 실행 오경보 | 11/500 (2.2%) |
| 충돌 실행 선행경보 | 9/500 (1.8%) |
| 기준 경보와 검출시각 중첩 | 0/500 |
| 수치 발산 | 0/1,000 에피소드 |
| 검출 지연 중앙값 | 30.2 ms |
| 검출 지연 95백분위 | 74.3 ms |
| 검출 지연 최대 | 125.1 ms |

시드별 충돌 구분은 92/100, 96/100, 95/100, 96/100, 96/100이었다. 한 시드에만
의존한 결과가 아니라는 점은 확인했지만, 오경보가 완전히 제거됐다는 기존
60표본의 관찰은 더 큰 표본에서는 유지되지 않았다.

## 실패 위치

25개 실패의 동작 구간 분포는 다음과 같다.

- 놓기 천이: 14건
- 운반: 6건
- 집기 천이: 4건
- 복귀: 1건

실패 힘은 15.4–54.8 N, 중앙값 22.9 N이었다. 실제 미검출 16건과 충돌 전
경보로 판정할 수 없었던 9건을 구분해 원자료에 모두 남겼다. 놓기 접근이 가장
큰 사각이라는 기존 결론은 500표본에서도 유지됐다.

## 해석

확장 결과가 뒷받침하는 표현은 “추가 센서 없이 넓은 시뮬레이션 분포에서 약
95%의 충돌 구분률을 보였고 발산은 없었다”이다. 모든 환경에서 오경보가 없거나
충돌을 100% 검출한다고 주장할 수는 없다. 실제 적용 전에는 정상 반복 데이터로
임계값을 재교정하고, 놓기 상태 판정을 보강해야 한다.
