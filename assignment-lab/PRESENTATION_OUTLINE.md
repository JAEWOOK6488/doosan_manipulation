# 발표 개요 — 하중 천이 중 제어와 충돌 감지

## 1. 문제 정의

- 픽 앤 플레이스에서 상자 무게는 수십 ms 동안 작업대에서 로봇으로 연속 전달된다.
- `grip` 신호만 보고 모델을 빈손↔완전 하중으로 즉시 바꾸면 제어 토크가 튀고,
  정상 하중 전달을 외부 충돌로 오인한다.
- 목표: 기준 택트와 1 kHz 제어 주기를 유지하면서 제어 오차·토크 충격·오경보를
  줄이고, 천이 중 실제 충돌 민감도는 유지한다.

## 2. 기준 시스템과 사용 가능한 신호

- MuJoCo M1013, 탄성 J1–J3의 2질량 모델, 6초 픽 앤 플레이스 사이클.
- 제어기: 모터 엔코더 `th`, 차분 속도 `thd`, JTS `tau_s`, grip, 목표 궤적.
- 감지기: 위 신호와 직전 주기 적용 모터 토크 상당값 `tau_m`. 실기 전류토크에
  대응하지만 시뮬레이터가 실제 전류[A]를 계산하는 것은 아니다.
- 링크각 `q`와 실제 접촉력은 평가·분석용이며 최종 알고리즘에는 사용하지 않는다.

## 3. 기준선의 실패

- `grip ON/OFF` 순간 하중 모델 계단 전환.
- 8 kg: 집기/놓기 토크 계단 57.5/73.8 N·m, 최대 TCP 오차 14.00 mm.
- 정상 작업 한 사이클에서 충돌 오경보 7회.
- 완전히 천천히 움직이면 완화되지만 택트가 늘어 과제의 산업 조건과 맞지 않는다.

## 4. 제안 제어기

- 빈손·완전 하중 역동역학 사이를 하중률 `alpha(t)`로 보간.
- 집기: 25 ms smoothstep, 놓기: 질량에 따른 접촉 선행 시각으로 smoothstep.
- 놓기 직전 TCP를 1.25 mm 들어 올린 뒤 release하여 작업대 누름을 줄임.
- 기준 궤적의 전체 시간은 바꾸지 않음.

## 5. 제안 충돌 감지기

- 정상 구간: 전체 운동량 관측기 잔차 사용.
- 천이 구간: 빈손 잔차를 알려진 페이로드 토크 방향과 직교 방향으로 분해하고,
  정상 하중 응답의 예측값만 제거.
- 작업 전 두 교정 구간에서 JTS 오프셋·느린 드리프트·잡음 수준 추정.
- 교정 중 5 ms 평균 변화가 크면 샘플을 기준선에서 제외하고 충돌로 판정.
- 상태별 임계값, 고잡음에서만 20 ms 누적 증거, 충돌 후 latch.
- 안정 구간에는 `tau_ext=J_v^T f` 기반 Cartesian 힘 잔차를 병렬 사용하고,
  천이·고잡음 조건에서는 자동으로 끔.
- 중력 방향만 무시하지 않으므로 ±X/±Y/±Z 충돌을 계속 검사.

## 6. 표준 결과

| 8 kg 지표 | 기준 | 제안 |
|---|---:|---:|
| TCP RMS / 최대 오차 | 6.14 / 14.00 mm | 5.95 / 11.84 mm |
| 집기 / 놓기 토크 계단 | 57.5 / 73.8 N·m | 5.6 / 5.1 N·m |
| 놓기 작업대 최대 힘 | 101 N | 92 N |
| 충돌 없는 오경보 | 7 | 0 |
| 기준 사이클 | 6.0 s | 6.0 s |

- 표준 15 N 충돌: 0/8 kg의 집기·운반·놓기에서 모두 검출, 31–76 ms.

## 7. 경계·강건성 검증

- 집기/놓기 주변 16시각 × 6방향, 15 N: 96/96, 오경보 0,
  중앙/최악 49/180 ms.
- 기동·교정 0.1–1.3 s, 8시각 × 6방향, 15 N: 48/48,
  중앙/최악 29.5/91 ms.
- 전체 사이클 12시각 × 6방향: 15 N 72/72, 중앙/최악 35/93 ms;
  10 N은 59/72로 비보장.
- 0.1 s 간격 58시각 × 6방향 탐색: 15 N 348/348, 중앙/최악 32/138 ms.
- 공개 밖 질량·COM·방향 88조건: 충돌 72/72, 중앙/최악 28/93 ms.
- 센서 잡음·오프셋·드리프트·마찰 16시나리오, 64조건: 충돌 48/48,
  오경보·선행 경보·발산 0, 최악 100 ms.
- 연속 질량·COM·임의 3D 방향 60조건: 60/60, 오경보·발산 0,
  중앙/최악 23.0/93.8 ms.
- 18,000주기 벽시계 p99: 제어기 40.9 μs, 감지기 71.4 μs. CPU 최대는
  200.2/206.7 μs지만 벽시계 단발 정지는 1.24/3.25 ms였음.
- 모든 충돌 판정은 같은 조건의 무충돌 실행과 ±20 ms 대조.

## 8. 두 엔코더 확장과 결론

- 출력축 엔코더 단독 분석형: 91/96로 JTS 최종안보다 낮음.
- JTS+두 엔코더 융합: 96/96, 중앙 46.5 ms로 2.5 ms 개선.
- 현재 공식 콜백에는 출력축 `q`가 없으므로 제출안은 JTS 혼합 관측기.
- 결론: 하중 전달을 충돌과 함께 버리는 대신, 알려진 하중 방향의 정상 응답만
  모델링해 제거하면 택트와 전 방향 충돌 감도를 함께 유지할 수 있다.

## 9. 한계와 다음 단계

- 질량·COM을 안다는 가정과 시뮬레이터 접촉 파라미터에 의존한다.
- 실제 로봇에서는 JTS 영점·마찰·작업대 높이 분포로 다시 검증해야 한다.
- 고정 1.25 mm 호버는 작업대가 +2 mm 이상 높을 때 정상 접촉 경보가 생겼다.
- 다음 단계: 온라인 페이로드/하중률 추정, constrained observer, 실제 충돌
  데이터로 임계값의 확률적 false-positive/false-negative 평가.
