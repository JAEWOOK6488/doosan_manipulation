# Motion Lab — 로컬 MuJoCo 대시보드

Week9 시뮬레이터 작업 사본을 실행·분석하는 웹 UI입니다. 제어·감지 입력과 별도로
출력축 링크 상태와 실제 접촉력을 분석 채널로 표시합니다.

## 실행

```bash
cd doosan_manipulation/mujoco-dashboard
../assignment-lab/.venv/bin/python server.py
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 서버 종료는 Ctrl+C.
다른 키트 경로는 `MUJOCO_KIT` 환경변수로 지정할 수 있습니다.

서버 실행 중 API·센서열·동역학 표시를 점검하려면 다음을 실행합니다.

```bash
../assignment-lab/.venv/bin/python smoke_test.py
```

- 0–8 kg(0.5 kg 단위), 무게중심 각 축 -100~100 mm, 최종 개선안/기준
  서보/기준 계산 토크, ±X/±Y/±Z 외력 실험
- 1ms 기록을 재생·탐색. 브라우저는 실시간 1kHz 제어 루프가 아닙니다.
- 입력측 모터각, 출력측 링크각, 두 축의 비틀림, JTS 토크, 전류 기반 모터토크
  상당값, 관측기 관절잔차, Cartesian 힘 잔차
- MuJoCo 실제 렌더링, 접촉 구간 확대, CSV 저장, 빈손·입력 하중의 명목
  M/g와 TCP J 계산
- 실제 링크 각도 및 접촉력은 분석에만 사용. 기준 제어기 입력은 변경하지 않습니다.
- Cartesian 힘 잔차는 JTS 관절잔차와 명목 자코비안으로 계산한 파생값이며,
  실제 충돌력 정답 채널과 구분해 표시합니다.
- 충돌 시험은 같은 질량의 무충돌 실행을 자동으로 대조합니다. 검출 시각 주변
  ±20 ms에 자연 경보가 있으면 지연값 대신 `구분 불가`로 표시합니다.
- 서버는 localhost에만 열립니다. 단일 사용자 실험용이며 마지막 실행 하나를 메모리에 보관합니다.
- CSV 열 이름에 링크각·목표각·모터각, 모터 전류 기반 토크 상당값, JTS,
  관측기 잔차와 단위를 명시합니다. 6,000행이 1 ms 간격 한 사이클입니다.
